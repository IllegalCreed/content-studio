# 接入 Content Studio 项目

## 第一步：读取项目快照

调用 `get_project_view` 读取当前项目的活动、内容、素材和任务快照。该工具不
执行任何外部发布。

以快照中的 `projectId` 作为后续所有工具的作用域。不要猜测或编造 ID；快照为空
或运行时不可用时，如实向用户报告，不要伪造数据。

## 第二步：理解本地工具边界

- 所有 MCP 工具只做本地登记、制作执行和任务跟踪，不会自动发布到渠道；
- 不接受、不读取、不记录任何密码、Cookie、Token 或浏览器凭据；
- 渠道登录或验证码要求一律拒绝，改用 `review-and-handoff` 的人工确认包；
- 项目文件只允许登记已确认的产物摘要，不要写入未知路径。

## 第三步：登记已有产物

活动产物使用 `register_activity_artifact` 登记本地文件摘要（不读取文件内容、
不接受任意路径）。登记后产物才可被后续发布安排引用。
